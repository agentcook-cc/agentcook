# Typography — 字体系统

> 中英文混排是 agentcook 的核心场景(教程读者 90% 中文用户 + 海外破圈预备 10% 英文)。**字体栈、行高、字重的选择必须同时为中英文优化**。

---

## 1. 字体栈

### sans(默认正文)

```
'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif
```

**当前问题(Day 6 review T1 红字证据)**:**缺中文 fallback**。Inter 不含 CJK,Mac/iOS 靠系统自动 PingFang SC 兜住,Win Chrome 上回退到中易宋(SimSun) — 衬线、字重不齐、视觉灾难。

<Canvas of={TypoStories.ChineseFallbackMissing} />

**Day 14-15 P0-3 修法**:加 `'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei'` 三档中文 fallback。

### mono(代码 / 等宽)

```
'JetBrains Mono', 'Fira Code', monospace
```

同样**缺中文等宽 fallback**(代码块嵌中文注释会跳字)。Day 14-15 加 `'Sarasa Mono SC'` 或 `'PingFang SC'`。

## 2. 字号 — 8 档

```
xs   0.75rem  (12px)   小标 / 时间戳
sm   0.875rem (14px)   表单提示 / 次要文字
base 1rem     (16px)   正文(默认)
lg   1.125rem (18px)   段落强调 / 子标题
xl   1.25rem  (20px)   区块标题
2xl  1.5rem   (24px)   页面 H2
3xl  1.875rem (30px)   页面 H1
4xl  2.25rem  (36px)   landing hero(Phase 3 加 5xl/6xl 更大档)
```

## 3. 字重 — 4 档

`normal (400)` / `medium (500)` / `semibold (600)` / `bold (700)`

**双栈使用习惯**:

- admin(Element Plus 紧凑)— 默认 400,标题 600,正文几乎不用 500/700
- app(shadcn/ui 现代)— 默认 400,标题 600/700,UI 强调用 500

<Canvas of={TypoStories.FontWeights} />

---

## 4. 行高

`tight (1.25)` / `normal (1.5)` / `relaxed (1.75)`

**中英混排准则**:
- **正文**:用 `normal` (1.5) — 中文字符方块比英文宽 + 高,需要更多行间距才不挤
- **标题**:用 `tight` (1.25) — 标题字号大,过宽行高会让标题显得松散
- **大段阅读(blog / docs)**:用 `relaxed` (1.75)

## 6. 给业务代码的写法

```jsx
{/* ✅ admin */}
<h1 class="text-2xl font-semibold leading-tight">Plugin 管理</h1>
<p class="text-sm text-neutral-600">共 24 个插件</p>

{/* ✅ app */}
<h1 className="text-3xl font-bold leading-tight">Your AI Agents</h1>
<p className="text-base text-neutral-600 leading-relaxed">Pick a plugin...</p>

{/* ✅ 直接消费 CSS variables(自定义组件)*/}
<h2 style={{
  fontSize: 'var(--typography-font-size-xl)',
  lineHeight: 'var(--typography-line-height-tight)',
  fontWeight: 'var(--typography-font-weight-semibold)',
}}>...</h2>
```

**禁止**:
- 在组件里硬编码 `font-size: 14px` / `font-weight: 600`
- 用 inline `style={{ fontFamily: 'Helvetica' }}` 绕过 design tokens
