# Optimize a product listing

Inputs to collect (ask once if missing): product, target marketplace,
target customer, 3-5 key features, current title/bullets if any.

1. **Title** (≤ 200 chars): core keyword first, then brand, key spec,
   and two use-case phrases (e.g. "for gym, commute").
2. **Five bullets**: each starts with a CAPITALIZED benefit (2-4 words),
   then the feature that delivers it. One bullet addresses the top
   complaint category for this product type.
3. **Backend keywords**: 10-15 terms not already in the title, no brand
   names of competitors.
4. Show before/after side by side when the user supplied a current
   listing, and explain the three most impactful changes.
5. If a `web_search` tool is available, check current best practices
   for the category before writing.
