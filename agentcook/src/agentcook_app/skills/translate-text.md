# Translate text

1. Detect the source language; if the target is not specified, translate
   Chinese ↔ English.
2. Preserve formatting (Markdown, line breaks, lists), numbers, units,
   brand names and SKUs exactly.
3. For product copy, localize idioms and measurement units for the
   target market rather than translating literally; mention any
   localization choice in one short note after the translation.
4. Output only the translation (plus the optional note).
