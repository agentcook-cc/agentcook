### Playwright 失败根因分析

**症状**：`loginAsAlice()` 中 `waitForURL(/\/dashboard$/)` 超时 10s

**根因**：admin 的 auth store 在 headless Chromium 中调用 `POST /auth/login` 后，router push 到 `/dashboard` 未成功触发。可能原因：
1. Java CORS 配置未覆盖 Playwright 的 `http://localhost:5173` origin（headless 模式）
2. Auth store 的 login 逻辑依赖 `XMLHttpRequest`/`fetch` 响应后的 `router.push()`，在并发 5 workers 下竞争 localStorage

**修复建议**（给 B/D）：
- D：确认 `SecurityConfig` 的 CORS `allowedOrigins` 包含 `http://localhost:5173`
- B：admin Login.vue 增加 `data-testid` 属性方便 Playwright selector 稳定定位
- C Day 34+：加 `webServer` 配置到 playwright.config.ts 自动启动 admin dev
