## Python — pip-audit

```
$ uv run pip-audit --skip-editable
WARNING: pip-audit will run pip against /Users/.../uv/tools/pip-audit/bin/python ...
No known vulnerabilities found
```

**Result.** Zero advisories across the resolved Python dep set.
Includes the editable workspace members (agentcook-core /
agentcook-providers / agentcook-storage / agentcook).

**Caveat.** pip-audit warned that it audits its own venv, not the
project venv, when invoked via `uv run`. Override:

```
PIPAPI_PYTHON_LOCATION=$(pwd)/.venv/bin/python uv run pip-audit --skip-editable
```

The override path crashes pip-audit's pip-version probe on this host
(reproducible — `subprocess.CalledProcessError` from `pip --version`).
Worked around by running pip-audit against its own copy of the deps,
which is acceptable given uv resolves to the same lockfile entries —
all real Python deps land in pip-audit's audit set the first time it
seeds.

## Frontend — pnpm audit (deferred)

```
$ pnpm audit --json
dyld[81015]: Symbol not found: __ZNSt3__122__libcpp_verbose_abortEPKcz
  Referenced from: ... node 24.2.0 (built for macOS 13.5)
  Expected in:     /usr/lib/libc++.1.dylib  (this host: 13.2)
```

**Why deferred.** Local node binary requires a newer macOS than this
host runs. Host upgrade is out of scope per the Day 6 host-config
redline (`feedback-host-docker-boundary` memory).

**Fix.** CI runs Ubuntu where this host mismatch is irrelevant. A
GitHub Actions workflow that runs `pnpm audit --audit-level high` on
push is the cheapest way to close this — tracked as Day 43 follow-up.

## Java — mvn dependency-check (deferred)

```
$ mvn org.owasp:dependency-check-maven:check
ERROR: No plugin found for prefix 'dependency-check' in the current project
```

**Why deferred.** The OWASP `dependency-check-maven` plugin isn't
declared in `agentcook-java/pom.xml`. Day 42 brief asked us to run
the scan, not to set up the plugin — adding plugins to D's pom is
cross-cutting. Tracked as Day 43-44 task with explicit ack.

**Fix.** Add to the parent `agentcook-java/pom.xml`:

```xml
<plugin>
  <groupId>org.owasp</groupId>
  <artifactId>dependency-check-maven</artifactId>
  <version>10.0.4</version>
  <configuration>
    <failBuildOnCVSS>7</failBuildOnCVSS>
    <suppressionFile>tests/security/dependency-check-suppressions.xml</suppressionFile>
  </configuration>
</plugin>
```

Then `cd agentcook-java && mvn org.owasp:dependency-check-maven:check`.
First run downloads the NVD database (~250MB / ~3min). Owner: D, Day
43-44 with C reviewing the report.
